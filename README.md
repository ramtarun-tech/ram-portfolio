# Ram Tarun — Portfolio

Live site: [ramtarun-tech.github.io/ram-portfolio](https://ramtarun-tech.github.io/ram-portfolio/)

A small, responsive portfolio built with HTML, CSS, and JavaScript. It presents my background, selected work, skills, education, and contact details.

## Run locally

1. Clone this repository.
2. Open `index.html` in a browser, or serve the folder with a local static server.

There are no package installs or build steps.

## Project files

- `index.html` — page structure and portfolio content
- `style.css` — responsive layout and visual styles
- `script.js` — mobile navigation and small page interactions

## Deployment

GitHub Actions deploys the static site to GitHub Pages when changes are pushed to `main`. The workflow is in `.github/workflows/deploy.yml`.
